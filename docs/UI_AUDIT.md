# dirMover 界面审计与重设计（1.4.0）

本文档记录 1.4.0 界面的逐项审计结果：界面上每个功能、每个按钮的职责、可用状态与本次做出的调整。
审计对象为 `src/gui/MainWindow.cpp` 中的全部页面、按钮、列表与对话框。

## 1. 信息架构

| 项 | 1.3.0 | 1.4.0 | 原因 |
|---|---|---|---|
| 一级导航 | 顶部分段页签（规则/计划/关于） | 左侧导航栏（规则/计划/服务/关于），1.4.5 收敛为（规则/计划/设置） | 页签不适合承载 4 个以上入口；1.4.5 起把「服务」「运行参数」并入设置页，导航更贴近传统工具软件 |
| 服务控制 | 混在「关于」页 | 独立「服务」页 | 关于页应只描述产品；服务安装/启停是高频操作，需要独立入口与状态展示 |
| 窗口 | 固定 880x760，不可缩放 | 初始 1000x740，可缩放，最小 900x660 | 规则列表与日志需要随窗口自适应，小屏也能容纳 |
| 页面容器 | 整页白色卡片 | 灰底 + 白色圆角卡片（16px 边距） | 明确「窗口背景 / 内容卡片」两层，视觉更轻 |

## 2. 规则页

| 控件 | 行为 | 可用状态 | 本次调整 |
|---|---|---|---|
| 新建规则 | 选择未迁移目录 → 编辑规则（监视/目标目录、白名单） | 始终可用 | 移到页头右侧，主按钮（蓝色） |
| 导入规则 | 从另一个目录的 `dirmv.ini` 导入一条规则 | 始终可用 | 与「新建规则」同组，次级按钮 |
| 规则列表 | 显示监视目录、目标目录、白名单数量、已迁移数量、状态、操作 | — | 无网格线、整行选中、选中行浅蓝底；列宽随窗口自适应（目录两列平分剩余宽度）；1.4.5 起为 7 列，新增「已迁移」列；状态列 1.4.3 起显示「已启用 · 运行中 / 已启用 · 后台已停止 / 已停用 / 不可用」，每 2 秒随服务状态刷新 |
| 列表首列复选框 | 勾选需要批量启用/停用的规则；表头可全选 | — | 与「选中行」明确分离：复选框只服务「启用/停用」 |
| 启用 / 停用 | 对**勾选**的规则批量启用或停用自动迁移 | 勾选了行时可用 | 按钮文案从「启用/停用」保持不变，但移入「选中规则」分组，语义由标签澄清 |
| 编辑 | 编辑**选中**规则的目录与白名单 | 选中一行时可用 | 双击行、点击「操作」列同样进入编辑 |
| 删除 | 删除**选中**规则，并恢复该规则已迁移的目录 | 在「规则详情」弹窗内（左下角「删除此规则」） | 1.4.4 起从规则页移入编辑弹窗；红色描边按钮；删除前有确认与恢复提示 |
| 开始迁移 | 迁移选中规则下尚未迁移的目录 | 选中一行时可用 | 主按钮（蓝色），与「恢复」「停止」区分 |
| 恢复 | 把选中规则已迁移的目录恢复回原位置 | 选中一行时可用 | 次级按钮 |
| 扫描接管… | 目标目录已有数据、原位置缺链接时接管并补链接 | 选中一行时可用 | 省略号表示会先弹出确认/预览 |
| 从目标目录生成规则… | 目标目录已有数据但原位置链接丢失时：选择目标目录 + 新监视目录，扫描一级子文件夹、建链接并纳入规则 | 选中一行时可用 | 1.4.5 起由「重建链接…」升级，省略号同上 |
| 停止 | 停止当前正在执行的迁移/恢复 | 始终可用（无任务时点击只记日志） | 放在任务行最右侧，红色描边，避免误触主操作 |
| 进度条 + ETA | 显示当前任务进度与预计剩余时间 | — | 细进度条（6px），右侧 ETA 文本 |
| 日志 | 追加显示运行日志 | — | 等宽字体、只读、带边框；高度随窗口伸缩 |
| 「选中规则」「任务」标签 | 分组说明 | — | 新增，解决 1.3.0 中「按钮作用于勾选还是选中行」的歧义 |

规则页整体采用**自下而上**的布局计算：日志固定贴底，任务行、操作行、列表依次向上排布，
窗口变高时只有列表变高，避免按钮被挤出可视区域。

## 3. 计划页

| 控件 | 行为 | 本次调整 |
|---|---|---|
| 保存设置 | 校验并保存定时与运行参数 | 从页面底部的大按钮移到页头右侧，减少视线跳跃 |
| 定时间隔 | 不定时 / 每天 / 每周 / 每月 / 每 N 天 | 与「时刻」同行；切换后只显示相关字段，避免无效输入 |
| 时刻（时:分） | 定时触发的时刻 | 两个数字输入框 + 冒号，同行对齐 |
| 周几 / 每月几号 / 每几天 | 周期细节 | 三组控件共用同一位置，按周期类型显示其中一组 |
| 下次运行 | 显示下次计划执行时间 | 置灰小字，紧随定时行 |

> 1.4.5 起「运行参数」整体移入**设置页**，计划页只保留定时设置，页面更聚焦。

## 4. 设置页（运行参数 / 后台服务 / 关于）

**运行参数**

| 控件 | 行为 | 说明 |
|---|---|---|
| 线程数 | 并发迁移目录数，0=自动（最多 8） | 与链接类型同行 |
| 链接类型 | 符号链接（需管理员）/ 目录联接（Junction） | 同上 |
| 移动模式 | 迁移成功后删除源数据（关闭则保留源） | 复选框，两列排布 |
| 启用实时监视 | 目录出现即触发迁移 | 同上 |
| 检测文件占用 | 迁移前检测占用，占用则跳过并创建一次性重试任务 | 与重试间隔同行 |
| 重试间隔（分钟） | 占用/失败后创建一次性重试任务的延迟；0=默认 5 分钟 | 说明文字补充了 0 的含义 |
| 保存设置 | 校验并保存运行参数 | 页头下方主按钮 |

**后台服务**

| 控件 | 行为 | 可用状态 |
|---|---|---|
| 大号状态文字 | 未安装 / 已安装（已停止）/ 运行中 / 已暂停 / 状态切换中 / 无法查询 | 每 2 秒自动刷新；运行中为绿色、暂停为橙色 |
| 安装服务 | 安装并设为开机自动启动 | 仅「未安装」时可用 |
| 启动服务 | 启动后台服务 | 仅「已停止」时可用 |
| 停止服务 | 停止后台服务，等待当前任务收尾 | 运行中或已暂停时可用 |
| 卸载服务 | 卸载服务（不影响已迁移的数据） | 已停止或已暂停时可用 |
| 服务日志 | 显示日志路径 | — |
| 打开日志 | 用默认程序打开 `dirmv_service.log` | 始终可用 |

**关于**

显示名称、动态版本号（读取 exe 版本资源）、联系方式（yhdhz@0916@outlook.com / 衍荒）与配置文件路径。
1.4.5 起服务控制与版本信息合并进设置页，导航收敛为「规则 / 计划 / 设置」三项。

## 6. 交互与视觉一致性

- 主操作统一蓝色实心（新建规则、开始迁移、保存设置）；危险操作红色描边（删除、停止）；其余为白底描边按钮。
- 所有按钮统一高度 34px（列表行内 30px），圆角 7px，悬停/按下/焦点均有反馈。
- 每个操作按钮与导航项都有 tooltip（一句话说明），降低「扫描接管」「重建链接」这类术语的理解成本。
- 对话框（新建规则/选择目录）与主界面使用同一套颜色、字体、圆角按钮。
- 底部状态通过日志区呈现，不再额外占用状态栏。

## 7. 键盘与 DPI

- 进程声明 System DPI aware，125%/150% 下文字清晰；所有尺寸经 `theme::S()` 缩放。
- Tab 可在输入框、按钮间移动；空格/回车可触发自绘按钮。
- 列表支持双击编辑、单击「操作」列编辑。

## 8. 已知限制（后续可做）

1. 下拉框（定时间隔/链接类型/周几）仍使用系统原生渲染，与自绘按钮风格略有差异；如需完全统一需 owner-draw 组合框。
2. 日志未按级别着色（Trace/Info/Warn/Error 目前同色）。
3. 批量任务（例如对多条勾选规则同时迁移）尚未提供入口，当前批量操作只有启用/停用。
4. 列表未提供列排序与右键菜单。
