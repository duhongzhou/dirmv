# dirMover 界面审计与重设计（1.4.7）

本文档记录 1.4.0 起界面的逐项审计结果，并在 1.4.7 按最新结构更新：界面上每个功能、每个按钮的职责、可用状态与调整原因。
审计对象为 `src/gui/MainWindow.cpp` 中的全部页面、按钮、列表与对话框。

## 1. 信息架构
| 项目 | 1.4.6 及之前 | 1.4.7 | 调整原因 |
|---|---|---|---|
| 一级导航 | 顶部分段页签（规则/计划/关于） | 左侧导航栏（规则/任务/大小/计划/设置） | 页签不适合承载多个入口；1.4.6 起「任务」独立成页（迁移/恢复/接管/进度/日志），「运行参数、后台服务、关于」统一进设置页；1.4.7 起新增「大小」页（左侧第 3 项），更贴近传统工具软件 |
| 大小统计 | 无（1.4.7 新增） | 左侧第 3 项「大小」页 | 直接子目录占用是迁移决策的关键依据；单独成页，用左右双列表对比监视目录与目标目录，避免与规则配置、任务执行混在一起 |
| 服务控制 | 混在「关于」页 | 设置页的「后台服务」分组 | 服务安装/启停是低频但重要的管理操作，与运行参数、版本信息同属设置；状态用大号彩色文字，一眼可见 |
| 任务执行 | 与规则列表混排 | 独立「任务」页 | 迁移/恢复/接管是「动作」，规则页只负责「配置」；分开后规则页不再因按钮过多而拥挤，日志也能获得更大空间 |
| 窗口 | 固定 880x760，不可缩放 | 初始 1000x740，可缩放，最小 900x660 | 规则列表与日志需要随窗口自适应，小屏也能容纳 |
| 页面容器 | 整页白色卡片 | 灰底 + 白色圆角卡片（16px 边距）；设置页再分三个圆角分组面板 | 明确「窗口背景 / 内容卡片 / 分组面板」层次，视觉更轻 |

> 页面清单（5 页）：**规则 / 任务 / 大小 / 计划 / 设置**，分别对应左侧导航 ID 2001–2005。

## 2. 规则页

| 控件 | 行为 | 可用状态 | 调整说明 |
|---|---|---|---|
| 新建规则 | 选择未迁移目录 → 编辑规则（监视/目标目录、白名单、启用） | 始终可用 | 页头右侧，主按钮（蓝色） |
| 导入规则 | 从另一个目录的 `dirmv.ini` 导入一条规则 | 始终可用 | 与「新建规则」同组，次级按钮 |
| 规则列表 | 显示监视目录、目标目录、白名单数、已迁移数、状态、详情 | — | 6 列；1.4.6 起移除多选复选框与「选中规则」行；无网格线、整行选中、选中行浅蓝底；目录两列平分剩余宽度；状态每 2 秒随服务状态刷新（已停用/不可用/已启用 · 运行中/已启用 · 后台已停止/已启用 · 服务切换中） |
| 详情列 | 打开该行的「规则详情」 | 始终可用 | 单元格文字「详情」；1.4.6 起由「操作/编辑」改名，避免与「执行动作」混淆 |
| 双击行 | 打开该行的「规则详情」 | 始终可用 | 与「详情」列等价 |
| 规则详情 | 修改目标目录、白名单、启用状态；左下角「删除此规则」 | 弹窗 | 监视目录只读；改目标目录会询问是否整体搬迁旧目标数据并重建链接；**关闭/取消时逐项比较输入与配置，无实际改动直接关闭、不弹保存提示** |
| 删除规则 | 先还原该规则全部已迁移目录，全部成功才删除 | 规则详情内（红色描边） | 个别失败则标记「待删除（还原失败）」并保留，重试仅处理失败项 |

规则页只负责「配置」：列表占满页面高度（`listH = bottom - listTop`），不再有底部操作行与日志区。

## 3. 任务页

| 控件 | 行为 | 可用状态 | 说明 |
|---|---|---|---|
| 开始迁移 | 迁移**全部已启用且配置可用**的规则下尚未迁移的目录 | 始终可用（无可用规则时提示） | 服务运行时经命名管道交给后台服务；服务未运行则本进程逐条执行；无需选中规则 |
| 恢复 | 把全部已启用规则已迁移的目录恢复回原位置 | 始终可用 | 同上，作用于全部已启用规则 |
| 扫描接管… | 扫描全部已启用规则的目标目录，接管已有数据并补建链接 | 始终可用 | 省略号表示先给出汇总确认 |
| 从目标目录生成规则… | 选择目标目录 + 新监视目录，扫描一级子文件夹、建链接并纳入规则 | 始终可用 | 目标数据不移动、不删除 |
| 停止 | 停止当前正在执行的迁移/恢复 | 始终可用（无任务时只记日志） | 最右侧，红色描边，避免误触主操作 |
| 进度条 + ETA | 当前任务进度与预计剩余时间 | — | 细进度条（6px），右侧 ETA 文本 |
| 日志 | 追加显示运行日志 | — | 系统原生多行只读 EDIT（非 RichEdit），等宽字体、带边框、高度随窗口伸缩；1.4.6 起去掉「弹出日志…」和 ES_NOHIDESEL，同一时刻只有一处选区 |

## 4. 大小页

页头说明：「扫描监视目录与目标目录的直接子目录，按占用大小排序」。

| 控件 | 行为 | 可用状态 | 说明 |
|---|---|---|---|
| 规则选择 | 下拉选择要统计的规则，显示为「监视目录 → 目标目录」 | 始终可用（无规则时列表为空并提示） | 切换规则立即重新统计；每次进入大小页都会按当前规则列表重建下拉，并自动统计第一条规则 |
| 刷新 | 重新统计当前规则的两个目录 | 始终可用 | 页头右侧次级按钮；统计进行中再次点击直接忽略（不排队、不重入） |
| 监视目录列表 | 左侧列表：直接子目录、大小、占比（3 列） | 统计完成后填充 | 统计该规则监视目录的**直接子目录**，大小在子目录内部递归累计；按大小降序，占比 = 该子目录 / 监视目录合计 |
| 目标目录列表 | 右侧列表：直接子目录、大小、占比（3 列） | 统计完成后填充 | 与左侧同结构、同排序，便于并排对比 |
| 汇总 | 「监视目录合计 X（N 项） · 目标目录合计 Y（M 项）」 | 统计完成后更新 | 合计包含全部直接子目录；无规则时清空 |
| 状态 | 统计进行中显示「正在统计两个目录的大小…」，完成后清空 | — | 无可用规则时显示「没有可用的规则。」 |

交互要点：

- 统计在**后台线程**执行，通过 `WM_APP_SIZE` 把结果投递回 UI，不阻塞窗口操作；再次切到大小页会重新触发统计。
- 进入大小页即自动统计当前选中的第一条规则；规则列表为空时只显示「没有可用的规则。」，不启动线程、不填充列表。
- 目录中的**重解析点**（符号链接 / 目录联接）不计入统计，避免把已迁移目录重复计算。
- 只展示一级子目录，不展开层级；没有单独的取消按钮，切换页面后统计仍在后台完成并回填。

## 5. 计划页


| 控件 | 行为 | 本次调整 |
|---|---|---|
| 保存设置 | 校验并保存定时与运行参数 | 从页面底部的大按钮移到页头右侧，减少视线跳跃 |
| 定时间隔 | 不定时 / 每天 / 每周 / 每月 / 每 N 天 | 与「时刻」同行；切换后只显示相关字段，避免无效输入 |
| 时刻（时:分） | 定时触发的时刻 | 两个数字输入框 + 冒号，同行对齐 |
| 周几 / 每月几号 / 每几天 | 周期细节 | 三组控件共用同一位置，按周期类型显示其中一组 |
| 下次运行 | 显示下次计划执行时间 | 置灰小字，紧随定时行 |

> 1.4.5 起「运行参数」整体移入**设置页**，计划页只保留定时设置，页面更聚焦。

## 6. 设置页（运行参数 / 后台服务 / 关于）

**运行参数**

| 控件 | 行为 | 说明 |
|---|---|---|
| 线程数 | 并发迁移目录数，0=自动（最多 8） | 与链接类型同行 |
| 链接类型 | 符号链接（需管理员）/ 目录联接（Junction） | 同上 |
| 移动模式 | 迁移成功后删除源数据（关闭则保留源） | 复选框，两列排布 |
| 启用实时监视 | 目录出现即触发迁移 | 同上 |
| 检测文件占用 | 迁移前检测占用，占用则跳过并创建一次性重试任务 | 与重试间隔同行 |
| 重试间隔（分钟） | 占用/失败后创建一次性重试任务的延迟；0=默认 5 分钟 | 说明文字补充了 0 的含义 |
| 保存设置 | 校验并保存运行参数 | 页头下方主按钮 |

**后台服务**

| 控件 | 行为 | 可用状态 |
|---|---|---|
| 大号状态文字 | 未安装 / 已安装（已停止）/ 运行中 / 已暂停 / 状态切换中 / 无法查询 | 每 2 秒自动刷新；运行中为绿色、暂停为橙色 |
| 安装服务 | 安装并设为开机自动启动 | 仅「未安装」时可用 |
| 启动服务 | 启动后台服务 | 仅「已停止」时可用 |
| 停止服务 | 停止后台服务，等待当前任务收尾 | 运行中或已暂停时可用 |
| 卸载服务 | 卸载服务（不影响已迁移的数据） | 已停止或已暂停时可用 |
| 服务日志 | 显示日志路径 | — |
| 打开日志 | 用默认程序打开 `dirmv_service.log` | 始终可用 |

**关于**

显示名称、动态版本号（读取 exe 版本资源）、联系方式（yhdhz@0916@outlook.com / 衍荒）与配置文件路径。
1.4.5 起服务控制与版本信息合并进设置页；1.4.6 起「任务」独立成页；1.4.7 起导航为「规则 / 任务 / 大小 / 计划 / 设置」五项。

## 7. 交互与视觉一致性

- 主操作统一蓝色实心（新建规则、开始迁移、保存设置）；危险操作红色描边（删除、停止）；其余为白底描边按钮。
- 所有按钮统一高度 34px（列表行内 30px），圆角 7px，悬停/按下/焦点均有反馈。
- 每个操作按钮与导航项都有 tooltip（一句话说明），降低「扫描接管」「从目标目录生成规则」这类术语的理解成本。
- 对话框（新建规则/选择目录）与主界面使用同一套颜色、字体、圆角按钮。
- 底部状态通过日志区呈现，不再额外占用状态栏。

## 8. 键盘与 DPI

- 进程声明 System DPI aware，125%/150% 下文字清晰；所有尺寸经 `theme::S()` 缩放。
- Tab 可在输入框、按钮间移动；空格/回车可触发自绘按钮。
- 列表支持双击行、单击「详情」列打开规则详情。

## 9. 已知限制（后续可做）

1. 下拉框（定时间隔/链接类型/周几）仍使用系统原生渲染，与自绘按钮风格略有差异；如需完全统一需 owner-draw 组合框。
2. 日志未按级别着色（Trace/Info/Warn/Error 目前同色）。
3. 启用/停用只能在「规则详情」内逐条切换，暂未提供批量入口。
4. 列表未提供列排序与右键菜单。
5. 大小页的统计没有取消入口、也没有进度提示；超大目录首次统计较慢，期间只能等待结果或切换页面。
